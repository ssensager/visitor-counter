# Visitor Counter (`visitor-counter`)

Студенческий MVP-проект: **«Система подсчёта посетителей на компьютерном зрении»**.  
Приложение получает видеозапись (`MP4` / `AVI`), обнаруживает людей с помощью `YOLOv8n`, отслеживает их перемещение через `ByteTrack`, считает входящих и выходящих при пересечении виртуальной линии и транслирует результат в минималистичный веб-дашборд.

---

## Стек технологий

- **Язык:** Python 3.11+ (проверяется под доступную версию PyTorch + CUDA)
- **ML / CV:** `YOLOv8n` (`ultralytics`), `ByteTrack`, `OpenCV`
- **Backend:** `FastAPI`, `Uvicorn`, `WebSocket`, `MJPEG`
- **Frontend:** `HTML5`, `CSS3`, `JavaScript` (раздаётся напрямую из FastAPI)
- **Опционально для презентации:** `python-pptx`

## Как работать участнику команды

1. **Клонируй репозиторий и создай свою ветку от актуальной `main`:**
   ```bash
   git checkout main
   git pull origin main
   git checkout -b feature/<твоя-ветка>
   ```
2. **Найди свой промпт в папке [`prompts/`](./prompts/README.md)** и передай его своему ИИ-агенту вместе с репозиторием.
3. **Работай строго в своей зоне ответственности** (см. [`PROJECT_SPEC.md`](./PROJECT_SPEC.md) и [`AGENTS.md`](./AGENTS.md)).
4. **Используй команды ведения контекста в чате с ИИ:**
   - `план` — составить план перед началом работы;
   - `чекпоинт` — сохранить текущий прогресс и проблемы в `reports/_wip_<role>.md`;
   - `финал` — прогнать проверки, сформировать чистовой отчёт `reports/<nn>_<role>.md` и подготовить ветку к Pull Request.
5. **Отправь свою ветку в GitHub и создай Pull Request в `main`.** Напрямую в `main` ничего не пушим.

## Целевой запуск (после сборки модулей)

После объединения веток приложение должно запускаться одной командой/скриптом из корня проекта (подробности появятся после интеграции и настройки `DevOps/QA`):

```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Веб-интерфейс будет доступен по адресу `http://127.0.0.1:8000/`.
