# ВАЖНО: PyTorch с поддержкой CUDA на Windows ставится ДО этого файла, иначе

#
#   CUDA 13.0 (драйвер NVIDIA 580+, рекомендуется для новых карт):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
#
#   CUDA 12.6 (драйвер NVIDIA 560+, если 13.0 не подходит):
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#
#   Проверка после установки:
#     python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# Если GPU нет - команду выше пропускаем, `pip install -r requirements.txt`
# поставит CPU-сборку torch, и приложение автоматически уйдёт в fallback на CPU.
